# 二师时光册 · 花都校园 3D 探索

[打开校园](https://z3275630-ops.github.io/ershi-time-atlas/) · [旧版校史网页](https://z3275630-ops.github.io/ershi-time-atlas/classic/)

通过校园总览、人物漫游和真实资料认识广东第二师范学院花都校区。包含图书馆、师德园专题，新生记忆任务与新手引导。

- 总览：拖动旋转、滚轮缩放，点击建筑查看介绍。
- 漫游：WASD / 方向键，或手机方向按钮；点击道路自动寻路。
- 角色：左上选择男生 / 女生，电脑也可按 C；切换保留位置和进度。
- 图书馆：靠近入口按 E，或点击地点进入照片、视频与原始 VR。
- 向导：当前为附资料出处的本地问答，真实 AI 服务尚未接入。

网页使用 Three.js、EasyStar、Driver.js 与 EZ-Tree。学生模型为 VRoid Project 的 CC0 作品，动作来自 MIT 许可的 Microsoft Rocketbox；使用 VRM 官方标准化骨骼离线转换。详细来源和许可证见[模型与组件来源](模型与组件来源.md)、assets 和 vendor 目录。

布局和建筑是参考资料重建的示意，部分场馆细节经过简化。进度仅保存在当前浏览器，不跨设备自动同步。原始 VR 是第三方网站，受其访问条件影响。

本地运行：在仓库目录执行 `python -m http.server 8769`，浏览器打开 `http://127.0.0.1:8769/`。GitHub Pages 从 codex/pages 分支根目录发布，无需构建。

当前版本完成离线蒙皮动作、角色切换、寻路、教程和静态资源检查；实际浏览器操作与手机帧率仍需试玩验证。
