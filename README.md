# 二师时光册 · 校园寻宝

[开始探索](https://z3275630-ops.github.io/ershi-time-atlas/) · [旧版校史网页](https://z3275630-ops.github.io/ershi-time-atlas/classic/)

在广东第二师范学院花都校园的3D场景中，观察五站线索，完成短互动，收服五只原创校园物件精灵，补完整本校史记忆册。

- 五站：图书馆、师德园、教学与艺术区、体育运动区、学生社区。
- 角色漫游：WASD/方向键或手机方向按钮；点击道路自动寻路；C键切换男生/女生。
- 图鉴：收服、回访、羁绊与精灵随行。记忆册支持保存单页和完成纪念卡。
- 存档：游客本机自动保存；导出备份、导入合并，保留同来源的旧版进度。
- 新手引导：16步，包含线索、互动、收服、收藏和模拟定位说明。

定位功能当前是明确标注的模拟演示，未读取GPS，不生成真实到访记录。账号同步、真实AI与摄像头AR尚未接入。向导提供有出处的本地资料与任务规则提示。

现有建筑布局和模型为参考资料重建的示意。校史资料与原创精灵对白分别标注，不虚构校园服务承诺或历史事件。实景、模型和组件来源见[模型与组件来源](模型与组件来源.md)，许可证随assets与vendor保留。

GitHub Pages从codex/pages根目录发布，首页使用预打包脚本campus-game.20261028.js；app.js及相关模块保留为源码。原3D版本可从Git提交845506f恢复。

本地运行：`python -m http.server 8771`。本轮发布的是已交付的寻宝预览，视频反馈的建筑与景观改动在后续独立预览中处理。离线任务/存档/教程/资源检查已通过，真实浏览器与手机体验未重新验收。
